## ⚽ Overview

EPL DLS Tournament Hub combines a **kit directory, player hub and tournament-management experience** into one football-focused interface.

## ✨ Features

- 🏆 Tournament creation and administration
- 📅 Fixtures, results and standings
- 👥 Player profiles and social interactions
- 👕 DLS team-kit and logo directory
- 📹 Kit import tutorial experience
- 🔔 Notifications and player activity
- 🎨 Responsive Premier League-inspired broadcast UI

## 🧱 Architecture

| Layer | Technology |
|---|---|
| Markup | HTML5 |
| Styling | CSS3 / Glassmorphism |
| Logic | JavaScript ES6+ |
| Storage / state | Project-dependent client-side + backend integrations |

## 🚀 Run Locally

```bash
git clone https://github.com/vince551/EPLDLS.git
cd EPLDLS
```

Open the application through a local static server if module imports or browser security rules require HTTP.
